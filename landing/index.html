How to Get Your API Keys

Follow these quick steps to get your own key for unlimited generation.

🔹 Google Gemini

Recommended for best narrative quality.

  1. Go to Google AI Studio.
  2. Sign in with your Google account.
  3. Click on Get API Key in the left sidebar.
  4. Click Create API Key.
  5. Copy and paste it into the app.

⚡ Groq

Recommended for lightning-fast generation.

  1. Go to the Groq Console.
  2. Create an account or sign in.
  3. Navigate to API Keys in the menu.
  4. Click Create API Key.
  5. Copy and paste it into the app.

🌐 OpenRouter

Access to various open-source models.

  1. Go to OpenRouter.ai.
  2. Sign in or create an account.
  3. Click your profile, then go to Keys.
  4. Click Create Key.
  5. Copy and paste it into the app.
